# С чего начать

## 0. Что нужно установить (всё бесплатно)
- Node.js 20+ — https://nodejs.org
- Git — https://git-scm.com
- Claude Code
- Аккаунт на GitHub

## 1. Открой папку в Claude Code
```
cd minusator
git init
claude
```

## 2. Первый запрос (скопируй целиком)
```
Прочитай CLAUDE.md, docs/SPEC.md и docs/ROADMAP.md.
Сделай Этап 1 из ROADMAP. Работай в текущей папке: тут уже лежат docs/,
samples/, src/dictionaries/ и .github/ — не удаляй их.
В конце проверь, что `npm run build` проходит, и объясни, как запустить сайт локально.
```

## 3. Дальше по этапам
Для каждого следующего этапа просто пиши:
```
/next-stage
```
Проверить логику на тестовом файле:
```
/check
```
Локальный запуск сайта: `npm run dev` → открыть ссылку из терминала.

## 4. Публикация на GitHub (после Этапа 6)
1. Создай пустой репозиторий на github.com (например, `minusator`).
2. Попроси Claude Code: «Запушь проект в https://github.com/<ник>/minusator, ветка main».
3. На GitHub: Settings → Pages → Source: **GitHub Actions**.
4. Через 1–2 минуты сайт будет по адресу `https://<ник>.github.io/minusator/`.
   Эту ссылку и отдаёшь девушке. Каждый новый пуш обновляет сайт автоматически.

## Советы
- Один этап = один запрос. Не проси «сделай всё сразу», будет хуже.
- Если что-то сломалось, вставь Claude Code текст ошибки целиком.
- Попроси её выгрузить реальный отчёт и проверь на нём. Реальные выгрузки
  Директа часто отличаются от тестовых, это нормально, Claude Code поправит парсер.
