# План работ

Делать строго по этапам. Каждый этап — отдельный запрос в Claude Code.
После каждого этапа: проверить на `samples/`, сделать git commit.

## Этап 1. Каркас ✅
- Vite + React + TS + Tailwind, `base: './'` в vite.config
- Пустая страница с заголовком и зоной загрузки файла
- `npm run build` проходит
- Vitest настроен

## Этап 2. Парсер ✅
- `src/lib/parser.ts`: CSV/TSV/XLSX, автоопределение разделителя и
  кодировки, поиск строки заголовков, маппинг колонок, нормализация чисел
- Ручной выбор колонок, если автоматически не нашлось
- Тесты на `samples/search_queries_sample.csv`
- В UI: после загрузки показать таблицу запросов

## Этап 3. Стеммер, виды кампаний и классификатор ✅
- `src/lib/parser.ts`: колонка «Упоминания брендов»; склейка одинаковых запросов внутри кампании
- `src/lib/stemmer.ts` (русский Snowball) + тесты
- `src/lib/campaigns.ts`: определение вида кампании по названию + тесты
- `src/lib/classifier.ts`: правила по видам кампаний (бренд / конкуренты / магазины),
  словари, гео, белый список, метрики
- В UI: блок кампаний с выбором вида; простые поля «слова бренда» и «конкуренты»
  (без сохранения — оно на Этапе 5); статусы 🔴🟡🟢 и причины в таблице, фильтры
- Обновить `samples/` и `EXPECTED.md` под виды кампаний

## Этап 4. Минус-слова ✅
- `src/lib/minus.ts`: сборка по видам кампаний, дедупликация, частотный анализ, форматы вывода
- Панель минус-слов с вкладками по видам кампаний, галочки, копирование, скачивание .txt
- Блок «Похоже на бренды» с кнопками «конкурент» / «магазин» / «не бренд»

## Этап 5. Настройки и сводка ✅
- Слова бренда, конкуренты (разрешённые и прочие), белый список, город, категории, пороги —
  с сохранением в localStorage
- Блок сводки с главной цифрой «бюджет на мусор» и разбивкой по видам кампаний

## Этап 6. Полировка и публикация ✅ (кроме пуша — ждёт репозиторий)

- Большие файлы (60 000+ строк): чтение без зависания страницы
- README с инструкцией и скриншотом
- Пуш на GitHub, включить Pages (Settings → Pages → Source: GitHub Actions)
