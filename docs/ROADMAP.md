# План работ

Делать строго по этапам. Каждый этап — отдельный запрос в Claude Code.
После каждого этапа: проверить на `samples/`, сделать git commit.

## Этап 1. Каркас
- Vite + React + TS + Tailwind, `base: './'` в vite.config
- Пустая страница с заголовком и зоной загрузки файла
- `npm run build` проходит
- Vitest настроен

## Этап 2. Парсер
- `src/lib/parser.ts`: CSV/TSV/XLSX, автоопределение разделителя и
  кодировки, поиск строки заголовков, маппинг колонок, нормализация чисел
- Ручной выбор колонок, если автоматически не нашлось
- Тесты на `samples/search_queries_sample.csv`
- В UI: после загрузки показать таблицу запросов

## Этап 3. Стеммер и классификатор
- `src/lib/stemmer.ts` (русский Snowball) + тесты
- `src/lib/classifier.ts`: словари, пользовательские правила, метрики
- В UI: статусы 🔴🟡🟢 и причины в таблице, фильтры

## Этап 4. Минус-слова
- `src/lib/minus.ts`: сборка, дедупликация, частотный анализ, форматы вывода
- Панель кандидатов с галочками, копирование, скачивание .txt

## Этап 5. Настройки и сводка
- Белый список, конкуренты, город, категории, пороги — с сохранением в localStorage
- Блок сводки с главной цифрой «бюджет на мусор»

## Этап 6. Полировка и публикация
- Вёрстка, пустые состояния, понятные ошибки («Не нашёл колонку с запросами…»)
- README с инструкцией и скриншотом
- Пуш на GitHub, включить Pages (Settings → Pages → Source: GitHub Actions)
