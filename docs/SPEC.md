# ТЗ: Минусатор

## Проблема
Специалист по контексту регулярно выгружает отчёт по поисковым запросам из
Яндекс Директа и вручную, глазами, ищет нецелевые запросы, чтобы добавить
минус-слова. Это занимает часы и часть мусора пропускается, а это слитый бюджет.

## Решение
Веб-страница: загрузил отчёт → увидел подсвеченные мусорные запросы с
причиной → поправил галочками → скопировал готовые списки минус-слов,
**отдельно для каждого вида кампании** (брендовая / категорийная / конкурентная / общая).

## Как устроена работа специалиста (важно для логики)
- Минус-слова задаются **на уровне кампании**. Обычно у клиента по одной кампании
  каждого вида, поэтому на выходе — один список минус-слов на вид кампании.
- Виды кампаний:
  - **Брендовая** — только запросы с брендом клиента.
  - **Категорийная** — запросы по категории товара без брендов («лосьон для ногтей»).
  - **Конкурентная** — запросы с брендами конкурентов, **которых разрешил заказчик**.
    Список разрешённых конкурентов спускает сам клиент; остальных конкурентов минусуют.
  - **Общая (микс)** — смесь всех запросов.
- Магазины, аптеки и маркетплейсы в запросах («столички», «максавит», «фикс прайс»)
  — мусор: с ними не конкурируют.
- Пересечение минус-слова с ключевой фразой не страшно: Директ отдаёт приоритет
  ключевой фразе, поэтому отдельной проверки на это не нужно.

## Пользовательский сценарий
1. Открывает сайт, перетаскивает файл отчёта (или выбирает через кнопку).
2. Инструмент сам находит нужные колонки. Если не нашёл — даёт выбрать вручную.
3. Видит список кампаний из отчёта с автоматически определённым видом
   (по названию, см. ниже). Может поменять вид вручную.
4. Указывает настройки клиента:
   - **слова бренда** клиента (например: ониксол, oniksol, ониксал);
   - **разрешённые конкуренты** — бренды, которые разрешил заказчик;
   - **прочие конкуренты** — чужие бренды, которые нужно минусовать (пополняется
     в процессе работы, см. «Поиск неизвестных брендов»);
   - (опционально) **белый список** — слова, которые никогда не минусуются;
   - (опционально) свой город — для гео-правила.
5. Видит таблицу запросов:
   - статус: 🔴 мусор / 🟡 подозрительно / 🟢 ок
   - причина (категория правила или метрика)
   - кампания и её вид, показы, клики, расход, конверсии
   - фильтры по виду кампании, статусу и категории, сортировка, поиск
6. Видит панель «Минус-слова» с вкладками по видам кампаний. В каждой — кандидаты
   с частотой, суммарным расходом и галочками. Может снять/поставить галочку,
   добавить слово вручную.
7. Нажимает «Скопировать» у нужного вида — получает список в формате Директа.
   Также можно скачать .txt.

## Входные данные
Отчёт по поисковым запросам Директа (Мастер отчётов или «Поисковые запросы»).
Форматы: CSV, TSV, XLSX. Реальные отчёты бывают на 60 000+ строк — должно работать.

Особенности, которые надо учесть:
- В выгрузках Директа сверху бывают служебные строки (клиент, название отчёта,
  период, пустая строка). Парсер сам находит строку заголовков.
- Сразу под заголовками бывает строка «Итого» — её пропускать.
- Строки с пустым поисковым запросом (Директ скрывает редкие запросы) пропускать.
- Разделитель может быть `;`, `,` или табуляция — определять автоматически.
- Кодировка: UTF-8 или Windows-1251 — определять автоматически.
- Числа могут быть с запятой как десятичным разделителем и с пробелами («1 234,56»).
- Прочерк «-» или пусто в метриках = 0.
- Один и тот же запрос может встречаться в нескольких группах одной кампании —
  такие строки **склеиваются** (метрики складываются).

Маппинг колонок (по вхождению подстроки, без учёта регистра):
| Поле        | Возможные названия |
|-------------|--------------------|
| query       | «Поисковый запрос», «Запрос» |
| campaign    | «Кампания», «Название кампании» |
| group       | «Группа», «Название группы» |
| impressions | «Показы» |
| clicks      | «Клики» |
| cost        | «Расход», «Стоимость» |
| conversions | «Конверсии» |
| brandMention | «Упоминания брендов в запросах» (необязательная, есть не во всех отчётах) |

Обязательна только колонка query. Без колонки campaign весь отчёт считается
одной кампанией, вид которой пользователь выбирает вручную.

Пример: `samples/search_queries_sample.csv`.

## Определение вида кампании по названию
Название режется на части по `_`, `-`, пробелам; регистр не важен.
Это не жёсткое правило агентства, а частая практика, поэтому вид всегда можно поменять вручную.

| Вид | Признаки в названии |
|-----|---------------------|
| Конкурентная | `cmpt`, `comp`, `konk`, «конкурент» |
| Категорийная | `category`, `cat`, `ctg`, `nbrnd`, «категор» |
| Брендовая | `brnd`, `brand`, «бренд» (именно как отдельная часть: `nbrnd` и `mixbrnd` — не брендовая) |
| Общая (микс) | `mix`, `mixbrnd`, всё нераспознанное |

Проверять в порядке: конкурентная → общая (`mix…`) → категорийная → брендовая → общая по умолчанию.
Пример: `…_brnd_brnd_…` — брендовая, `…_category_nbrnd_…` — категорийная,
`…_cmpt_nbrnd_…` — конкурентная, `…_kws_mixbrnd_…` — общая.

## Логика классификации
### 1. Правила по видам кампаний
«Бренд» — слово из списка слов бренда клиента. «Разрешённый конкурент» / «чужой бренд» —
слово из соответствующего списка. Сравнение по основам слов (стеммер).

| Что в запросе | Брендовая | Категорийная | Конкурентная | Общая |
|---------------|-----------|--------------|--------------|-------|
| Наш бренд | ok | 🔴 `own-brand` | 🔴 `own-brand` | ok |
| Нет нашего бренда | 🔴 `no-brand` | ok | — | ok |
| Разрешённый конкурент | 🔴 `competitor` | 🔴 `competitor` | ok | ok |
| Чужой бренд (не разрешён) | 🔴 `competitor` | 🔴 `competitor` | 🔴 `competitor` | 🔴 `competitor` |
| Магазин / аптека / маркетплейс | 🔴 `store` | 🔴 `store` | 🔴 `store` | 🔴 `store` |

Если слова бренда не заданы, правила `own-brand` и `no-brand` не работают
(и интерфейс подсказывает их заполнить).

### 2. Правила по словарям (`src/dictionaries/*.json`) — во всех кампаниях
Категории:
- `free` — бесплатно, даром, скачать, торрент…
- `jobs` — вакансии, работа, зарплата, резюме…
- `diy` — своими руками, самому, как сделать, инструкция…
- `info` — что такое, отзывы, состав, форум, википедия…
- `education` — курсы, обучение, для студентов, реферат…
- `used` — б/у, авито, бу, с рук…
- `adult` — 18+ контент (минимальный словарь)
- `stores` — аптеки, магазины, маркетплейсы (аптека, столички, максавит, фикс прайс…)

Каждый словарь — массив слов/фраз. Сравнение по основам слов (стеммер),
чтобы «бесплатно», «бесплатный», «бесплатные» ловились одним правилом.
Пользователь может включать/выключать категории (галочки в настройках).

### 3. Гео
Свой город → запросы с другими городами из `cities.json` получают `geo`.

### 4. Белый список
Слова, которые никогда не становятся минус-словами; запросы с ними не помечаются 🔴 (максимум 🟡).

### 5. Правила по метрикам (если есть колонки)
- Клики ≥ N и конверсий = 0 → 🟡 «кликают, но не конвертируются»
- Расход ≥ X и конверсий = 0 → 🟡 «тратит бюджет без результата»
- N и X настраиваются, по умолчанию N = 5, X = 500.

### Итоговый статус
- 🔴 — сработало правило вида кампании, словарное или гео
- 🟡 — сработало только метрическое правило, или 🔴 перебит белым списком,
  или в запросе упоминается неизвестный бренд (см. ниже)
- 🟢 — ничего не сработало
- Если у запроса были конверсии, в таблице это заметно, чтобы человек решил сам.

## Поиск неизвестных брендов
Сайт не знает всех брендов на свете, поэтому помогает их найти:
- Если в отчёте есть колонка «Упоминания брендов в запросах», запросы со значением
  «…брендов конкурентов», которые не объяснены ни одним списком, получают 🟡
  «упоминается чужой бренд».
- Блок «Похоже на бренды»: частые слова из таких запросов (и из 🔴/🟡 запросов вообще),
  которых нет в 🟢 запросах. У каждого слова кнопки «конкурент» / «магазин» / «не бренд».
  Выбор сохраняется в настройки клиента и сразу пересчитывает статусы.

## Сборка минус-слов — отдельно для каждого вида кампании
- Из 🔴 запросов берётся слово, на котором сработало правило
  (например, «бесплатно», чужой бренд, наш бренд в категорийной кампании), а не весь запрос.
- Для `no-brand` (запрос без бренда в брендовой кампании) одного «виноватого» слова нет —
  кандидатами становятся слова таких запросов, которых нет в 🟢 запросах этой кампании;
  специалист отмечает нужные галочками.
- Дополнительно: кнопка «Показать слова, которые есть только в 🔴/🟡
  запросах» — частотный анализ слов, которые не встречаются в 🟢 запросах.
- Стоп-слова русского языка (предлоги, союзы: в, на, для, и, с…)
  не предлагаются как минус-слова. Слова бренда в брендовой кампании и разрешённые
  конкуренты в конкурентной — тоже.
- Дедупликация по основе слова.
- Сортировка кандидатов по суммарному расходу, затем по частоте.

### Формат вывода (настраивается переключателем)
- По одному слову в строке: `бесплатно`
- С минусом в начале, через пробел: `-бесплатно -скачать -вакансии`
- Фиксация формы (`!слово`) — опционально, галочкой.

Показывать счётчик символов каждого списка. Предупреждать, если
список очень длинный (у Директа есть лимит на длину минус-фраз кампании —
актуальное значение указать в константе, легко поменять).

## Интерфейс
- Одна страница, светлая тема, аккуратный современный вид.
- Блоки: загрузка файла → кампании и их виды → настройки клиента (сворачиваемые) →
  сводка → таблица → минус-слова (вкладки по видам кампаний).
- **Сводка «Сколько бюджета ушло на мусор»** — главная цифра на экране,
  крупно, плюс разбивка по видам кампаний. Это то, что специалист покажет клиенту/руководителю.
- Настройки (слова бренда, конкуренты, белый список, город, категории, пороги)
  сохраняются в localStorage и подставляются при следующем визите.
- Пока читается большой файл — показывать, что идёт работа.
- Работает на десктопе; на мобильном — без поломок вёрстки.
- Внизу: «Файлы обрабатываются в вашем браузере и никуда не отправляются».
