# Словари

Каждый файл — категория мусорных запросов (массив слов/фраз в нижнем регистре).
Сравнение идёт по основам слов, поэтому достаточно одной формы слова.

- `stopwords.json` — служебные слова, которые НИКОГДА не предлагаются как минус-слова.
  «купить», «цена» и города тут намеренно: это частые целевые слова.
- `cities.json` — города для гео-правила (запрос с чужим городом = мусор).

Дописывать словари можно прямо здесь — пересборка подхватит.
